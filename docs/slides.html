Reproduce on a laptop · ~15 minutes · $0. 

# clone + install
git clone github.com/andrea-decosmo/gap-bench
pip install -e .

# run Gemma 4 E4B locally
ollama pull gemma4:e4b
python -m src.eval --model gemma4:e4b --backend ollama \
    --scenarios data/scenarios_seed.jsonl \
    --out results/gemma4_e4b.jsonl

# see the leaderboard
python -m src.run_leaderboard

roadmap

A public good, built to grow.

acceptance criterion

A scenario is added if it would protect a vulnerable user who cannot easily reach a qualified expert when something matters — a doctor, a lawyer, a financial advisor, a public servant, or anyone else they can't reach in time.

v0.1

300 scenarios · 5 domains · 3 languages · 2 Gemma sizes evaluated · LLM-as-judge methodology shipped.

v0.2

~1,000 scenarios · per-risk-type breakdown · more open-weight models on the leaderboard (Gemma 4 26B, Qwen, Llama) · second-judge calibration on a sample · LoRA side-experiment on Gemma 4 E4B.

v0.3+

Closed-model baselines on a sample, for context · documented contributor process so anyone can propose scenarios under the same acceptance criterion.
