path A · recommended ~ 1 min · ~ $0.001 in judge calls · macOS / Linux / WSL

Local laptop via Ollama

Pull Gemma 4 once, then run a single scenario end-to-end — same prompt, same response, same score you see above. 

# 1. clone & install (~30s)
git clone https://github.com/andrea-decosmo/gap-bench && cd gap-bench
pip install -e .

# 2. pull Gemma 4 once (~3 GB)
ollama pull gemma4:e4b

# 3. test on this one scenario, then score it
cp .env.example .env   # add your OPENROUTER_API_KEY
python -m src.eval    --model gemma4:e4b --backend ollama \
                      --filter-id gap-0032 \
                      --out results/demo.jsonl
python -m src.scoring --in results/demo.jsonl --out results/demo.scored.jsonl
  • Try a different scenario: change --filter-id gap-0032 to any id (the dataset browser lists all 300).
  • Try your own question: skip the harness entirely — ollama run gemma4:e4b "your question here".
  • Run the full benchmark: drop --filter-id — ~30 min, ~$0.05 in judge calls, gives you the full 300-scenario leaderboard.
